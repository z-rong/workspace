下载下这个分支代码，M_Feature_WFD_230412，编译一下， 有不明白的地方请教其坤。sharing_framework是投播框架代码。

```
repo init -u ssh://zengrong@gerrit.kaihongdigi.com:29418/KaihongOS_Future/manifest -b M_Feature_WFD_230412 -m default.xml --no-repo-verify && repo sync -c && repo forall -c "git lfs pull"
```

编译后需要使用一个投屏应用

```
hdc install D:\workspace\wfd-0428.hap
```

打开应用，然后就可以使用手机或者电脑的投屏进行屏幕播放了。

- 投屏使用的是wifi，不需要联网，但必须wifi正常，以太网也没有用。如果wifi异常那就无法使用
- 有的屏幕可能不支持投屏，暂时不清楚原因。

* 投屏结束后使用鼠标移动在黑边上会有重影
* 投屏画面未出现画面前移动鼠标出现黑影





* 投屏结束后再次投屏会卡顿，卡顿期间点击可能导致卡死
