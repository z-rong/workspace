## 简单的单元测试模块编写和测试

## 1、编写

### 目录结构

```

.
├── include
│   ├── dsensor_adapter.h
│   └── idsensor_adapter_listener.h
├── src
│   └── dsensor_adapter.cpp
└── test
    └── unittest
        ├── BUILD.gn
        ├── include
        │   └── dsensor_adapter_test.h
        └── src
            └── dsensor_adapter_test.cpp
```

### 编译配置

gn文件编写如下

* 首先需要导入test.gni
* 配置config，需要包含被测试函数头文件路径
* 配置测试源文件，包含测试文件、依赖等
* 最后配置group，必须包含testonly=true

```
import("//build/test.gni")
import("//kaihong/distributedhardware/distributed_sensor/distributedsensor.gni")

module_out_path = "distributed_sensor/services/dsensor_adapter_test"

config("module_private_config") {
  visibility = [ ":*" ]

  include_dirs = [
    "include",
    "${fwk_common_path}/utils/include",
    "${fwk_common_path}/log/include",
    "${fwk_utils_path}/include/log",
  ]

  include_dirs += [
    "${common_path}/include",
    "${services_path}/dsensoradapter/include",
  ]
}

## UnitTest dsensor_adapter_test
ohos_unittest("DSensorAdapterTest") {
  module_out_path = module_out_path

  sources = [
    "${services_path}/dsensoradapter/test/unittest/src/dsensor_adapter_test.cpp",
  ]

  configs = [ ":module_private_config" ]

  deps = [
    "${distributedsensor_path}/sensorhandler:distributed_sensor_handler",
    "${common_path}:distributed_sensor_utils",
    "//utils/native/base:utils",
    "//third_party/googletest:gmock",
    "//third_party/googletest:gtest_main",    
  ]

  defines = [
    "HI_LOG_ENABLE",
    "DH_LOG_TAG=\"sensoradaptertest\"",
    "LOG_DOMAIN=0xD004100",
  ]

  external_deps = [
    "hiviewdfx_hilog_native:libhilog",
    "ipc:ipc_core",
    "sensor_device_driver:libsensor_proxy_1.0",
  ]
}

group("d_dsensor_adapter_test") {
  testonly = true
  deps = [ ":DSensorAdapterTest" ]
}
```

配置完之后在会被编译到的BUILD.gn中添加编译目标group，添加依赖以及testonly=true

```
import("//build/ohos.gni")

group("distributed_sensor"){
  deps =[
    "//kaihong/distributedhardware/distributed_sensor/common:distributed_sensor_utils",
    "//kaihong/distributedhardware/distributed_sensor/interfaces/innerkits/sensor_sink:distributed_sensor_sink_sdk",
    "//kaihong/distributedhardware/distributed_sensor/interfaces/innerkits/sensor_source:distributed_sensor_source_sdk",
    "//kaihong/distributedhardware/distributed_sensor/interfaces/kits:distributed_sensor_native_js",
    "//kaihong/distributedhardware/distributed_sensor/sensorhandler:distributed_sensor_handler",
    "//kaihong/distributedhardware/distributed_sensor/services/sinkservice:distributed_sensor_sink",
    "//kaihong/distributedhardware/distributed_sensor/services/sourceservice:distributed_sensor_source",
    "//kaihong/distributedhardware/distributed_sensor/sa_profile:dsensor_sa_profile"
  ]
}
// 这个是自己添加的
group("sensor_test"){
  testonly = true
  deps = [
    "//kaihong/distributedhardware/distributed_sensor/services/dsensoradapter/test/unittest:d_dsensor_adapter_test"
  ]
}
```

## 2、编译

使用命令单独编译某个模块

```
./build.sh --product-name khdvk_rk3568_b --build-target sensor_test
```

生成的bin文件（可执行文件）在out/khdvk_rk3568_b/tests/unittest/distributed_sensor/services/dsensor_adapter_test/DSensorAdapterTest目录中

## 3、执行

生成的文件是一个可执行文件，需要发到板子里

先把生成的bin文件移到D盘里，然后使用命令发送到板子里

```
// 发送的可读写目录，有的目录是不允许读写的
hdc file send D:\start\DSensorAdapterTest /data/local/test
// 添加文件的可执行权限
chmod +x test
// 执行文件
./test
```

