### 文件管理测试

手动测试，下载应用手点。还要准备好资料测试。

```
hdc install C:\workspace\com_kaihong_documentmanager_1.0.1.hap
hdc file send C:\workspace\2056808.jpg /storage/media/100/local/files/Pictures/demo1.jpg
hdc file send C:\workspace\2056808.jpg /storage/media/100/local/files/Pictures/demo2.jpg
hdc file send C:\workspace\demo.mp4 /storage/media/100/local/files/Videos/demo.mp4
hdc file send C:\workspace\demo.ogg /storage/media/100/local/files/Audios/demo.ogg
hdc shell reboot
```

按照“共主干最小系统_V0130_文件管理0级测试用例..xlsx”文件进行0级用例测试(用手点应用查看图片测试)
