## miracast投屏升级

1、manifest仓新增miracast仓和live555仓的下载，使用extension路径

```
<project name="kh_miracast_framework" path="extension/multimedia/miracast_framework" groups="default,ohos:standard,ohos:system,ohos:chipset"/>
  <project name="kh_third_party_live555" path="third_party/live555" groups="default,ohos:standard,ohos:system,ohos:chipset"/>
```

2、build仓新增kh_multimedia子系统

```
"kh_multimedia": {
    "path": "extension/multimedia",
    "name": "kh_multimedia"
  },
```

3、vendor仓新增编译

```
{
      "subsystem": "kh_multimedia",
      "components": [
        {
          "component": "miracast_framework",
          "features": []
        }
      ]
    },
```

4、解决miracast仓编译问题

- kaihong路径替换为extension路径
- surface_2d:surface替换为graphic_surface:surface
- wificallback增加void OnP2pPrivatePeersChanged(const std::string &priWfdInfo)实现



5、添加selinux权限、添加用户组id、添加syscap

- selinux如果不加，可以在cfg文件中删除相关配置，暂时绕过

- 用户组id必须加，不然启动不了

base/startup/init/services/etc/passwd
```
miracast:x:10605:10605:::/bin/false
```
base/startup/init/services/etc/group
```
miracast:x:10605:
```

- syscap不加可能会有编译问题
