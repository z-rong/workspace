# Wanem环境搭建

vanem是一个可当作路由管理的linux镜像，通过设置相关参数管理网络中的数据。

使用设备：主机一台，路由器一个

## 1、下载安装

**下载地址**

https://sourceforge.net/projects/wanem/

**安装流程**：

1. 使用虚拟机安装，linux类型选择其它linux 3.x内核64位，在安装过程中是否配置ip选择n

2. 安装完成后，先查看本机window的ip地址
3. 使用命令配置临时ip地址，和windows的ip地址处于同一网段

```
ifconfig eth0 192.168.1.10 netmask 255.255.255.0
```

## 2、Wanem使用配置

在虚拟机中创建两个ubuntu系统，设置网络模式为桥接模式，分别作为PC1和PC2

安装网络库

```
sudo apt install net-tools
sudo apt install traceroute
```

三台虚拟设备地址如下

|       |    IP地址     |  系统  |
| :---: | :-----------: | :----: |
|  PC1  | 192.168.1.102 | ubuntu |
|  PC2  | 192.168.1.103 | ubuntu |
| WANEM | 192.168.1.10  | WANEM  |

测试PC1是否能够ping通PC2和WANEM

```
ping 192.168.1.103
ping 192.168.1.10
```

查看PC1的路由

```
ip r
```

在PC1中添加路由，经过WANEM

```
sudo ip route add 192.168.1.103 via 192.168.1.10

sudo ip route del 192.168.1.103 via 192.168.1.10 // 删除路由
```

查看PC1到PC2的路由地址是否经过192.168.1.10

```
ip r
traceroute 192.168.1.103
```

## 3、WANEM使用

在主机中使用浏览器打开WANEM的管理界面（注意大小写），不要使用虚拟机进行管理，以免WANEM启动后访问异常

http://192.168.1.10/WANem/

WANEM有三种模式

- WANanlyzer：网络分析模式，分析某个ip地址的网络

- Basic Mode：基础模式，可以设置网络带宽、延迟
- Advanced Mode：高级模式，对网络进行更细致的管理，包括丢包、错误数据、乱序等

通过设置WANEM的各种数据就可以控制网络包的丢失和错误了。

## 4、OS设备使用WANEM

设备接入同一网段

设备地址如下

|         |    IP地址     |   系统    |
| :-----: | :-----------: | :-------: |
| ubuntu  | 192.168.1.103 |  ubuntu   |
| windows | 192.168.1.101 |  windows  |
|  WANEM  | 192.168.1.10  |   WANEM   |
| os设备  | 192.168.1.100 | kaihongOS |

### 在ubuntu中部署rtsp服务器

在虚拟机中设置路由经过WANEM

```
sudo ip route add 192.168.1.103 via 192.168.1.10
```

查看配置是否生效

```
ip r
traceroute 192.168.1.103
```

### 在windows中部署rtsp服务器

在window的命令中设置路由经过WANEM

```
route add 192.168.1.100 mask 255.255.255.0 -p 192.168.1.10
route print
tracert 192.168.1.100 // 查看是否经过WANEM
```

### 两台OS设备互相使用

初始ip如下

|       |    IP地址    |   系统    |
| :---: | :----------: | :-------: |
| 设备1 | 192.168.1.1  | kaihongOS |
| 设备2 | 192.168.1.2  | kaihongOS |
| WANEM | 192.168.1.10 |   WANEM   |

**使用交换机配置**

设置设备1的ip和路由

```
ifconfig eth0 192.168.1.1 netmask 255.255.255.0
route add default gw 192.168.1.10
route add 192.168.1.2 gw 192.168.1.10
```

设置设备2的路由

```
ifconfig eth0 192.168.1.2 netmask 255.255.255.0
route add default gw 192.168.1.10
route add 192.168.1.1 gw 192.168.1.10
```

使用交换机配置，WANEM设置的延迟会翻倍，需要注意

**使用路由器配置**

设置设备1路由

```
ip rule del from all fwmark 0/0xffff iif lo lookup 104 pref 16000
ip rule del  from all fwmark 0/0x10000 lookup 99 pref 13000
ip route add default via 192.168.1.10 dev eth0 table main
ip route add 192.168.1.2 via 192.168.1.10 dev eth0 table main
```

设置设置2路由

```
ip rule del from all fwmark 0/0xffff iif lo lookup 104 pref 16000
ip rule del  from all fwmark 0/0x10000 lookup 99 pref 13000
ip route add default via 192.168.1.10 dev eth0 table main
ip route add 192.168.1.1 via 192.168.1.10 dev eth0 table main
```

路由器修改后可以进行ping命令的丢包，但是超级设备断连后无法重连，无法使用超级设备组网功能

```
ip rule del from all fwmark 0/0xffff iif lo lookup 104 pref 16000
ip rule del  from all fwmark 0/0x10000 lookup 99 pref 13000
ip route add default via 192.168.1.103 dev eth0 table main
ip route add 192.168.1.1 via 192.168.1.103 dev eth0 table main
```

Packet Limit：用来设置包的队列大小，默认为1000，当队列超过1000时，超过的包将被丢弃

Symmetrical network：对称网络，选中为Yes的时候，应用网络的规则将在数据包来回的方向上都生效

Choose BW：从快速列表选择带宽

Specify BW：自定义带宽

Delay：延时，这里设置的是单向的延时。Jitter，抖动；Correlation，相关性，用来设置这个包的延迟时间与上一个包的时间的相关度

Loss：丢包率；Correlation，相关性，以一定的概率发生突发的大量的丢包，但平均丢包率不会超过Loss定义的值

Duplication：重包率，以一定概率生成某个包的多份拷贝，并按随机时间到达目标端。Correlation，相关性，类似Loss的

Packet reordering：包重排序率，按概率将包的顺序打乱，gap用来确定包重排序的个数，不设置更接近真实的环境

Corruption：错包率，按概率产生噪音，即格式错误的包

Idle timer Disconnect：空闲断开定时器，当网络空闲时，按设定的时间对Type定义的协议断开连接。

Random Disconnect：按Type随机断开，MTTF，平均失效前时间，用Low和High定义两个极值，MTTF，平均恢复前时间

IP source address：匹配的源IP地址

IP source subnet：源IP地址的子网

IP dest address：匹配的目标IP地址

IP dest subnet：匹配的目标IP地址的子网

Add a rule set：添加一条规则

Apply settings：应用设置
