# @ohos.distributedHardware.khDistributedScreen（开鸿分布式屏幕）

开鸿分布式屏幕服务为开发者提供了一套简单易用的跨设备屏幕和多模输入功能接口。开发者通过调用这些接口，可以实现跨设备的屏幕共享和多模输入控制。该服务支持用户将组网认证过的其他KaihongOS设备的屏幕作为扩展显示区域，并支持将其他设备的多模输入（如触控、键盘、鼠标等）作为外设进行调用。

**主要功能**

- **跨设备屏幕共享**：支持用户将其他KaihongOS设备的屏幕作为扩展显示区域，实现屏幕内容的跨设备展示。
- **多模输入控制**：支持用户将其他KaihongOS设备的多模输入（如触控、键盘、鼠标等）作为外设进行调用，实现跨设备输入操作。
- **低时延**：提供高效的通信机制，确保屏幕共享和输入控制的低时延体验。
- **设备下线感知**：实时感知设备下线状态，确保服务的高可用性。
- **反控支持**：支持从目标设备反向控制源设备，提升交互灵活性。
- **主动投屏**：支持用户主动发起投屏，将本地屏幕内容投射到其他设备。
- **屏幕主动拉入**：支持用户主动拉取其他设备的屏幕内容到本地显示。
- **一投多**：支持将本地屏幕内容同时投射到多个设备，满足多屏协作需求。

> 说明：
>
> 本模块首批接口从API version 9开始支持。后续版本的新增接口，采用上角标单独标记接口的起始版本。

## 导入模块

```
import { khDistributedScreen } from '@kit.khDScreenKit'
```

## startPullScreen

startPullScreen(localDeviceId: string, remoteDeviceId: string, callback: AsyncCallback<number>): void

异步方式开始拉取屏幕，通过注册回调函数获取返回值。

**系统能力：** SystemCapability.DistributedHardware.khDistributedScreen

**参数：**

| 参数名         | 类型                   | 必填 | 说明                                     |
| -------------- | ---------------------- | ---- | ---------------------------------------- |
| localDeviceId  | string                 | 是   | 当前设备的设备ID。                       |
| remoteDeviceId | string                 | 是   | 远程设备的设备ID。                       |
| callback       | AsyncCallback\<number> | 是   | 回调函数。异步返回结果，失败时返回null。 |
**示例：**

```ts
import { BusinessError } from '@kit.BasicServicesKit';
let localDeviceId = "afbbeddfac"
let remoteDeviceId = "afaccf654c"
khDistributedScreen.startPullScreen(localDeviceId, remoteDeviceId, (error: BusinessError, result: number) => {
    if (result === 0) {
        console.info('Succeeded in starting pull screen');
    } else {
        console.error(`Failed to start pull screen, error message:${error.message}`);
    }
});
```
